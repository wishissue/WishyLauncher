# 8-bit theme credits

This theme contains no third-party images, fonts or wallpapers. The pixel look comes from the launcher's own pixel shapes, the built-in dither overlay and stepped animation, drawn with the bundled default font in capital letters.

The colour palette is inspired by the PICO-8 16-colour palette (by Lexaloffle). Individual colour values are not copyrightable, and no PICO-8 files are included. Licence: GPL-3.0-only.

To get a true pixel font, add one whose licence allows redistribution (for example an SIL OFL font), list it in `credits`, and reference it from `fonts` and `textStyles`.
